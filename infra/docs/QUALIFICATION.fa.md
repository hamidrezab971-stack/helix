اسکن واقعی Trivy برای هیچ runtime یافتهٔ Critical باقی نگذاشت، ولی یافته‌های
High باز هستند: برنامه ۴۴ مورد بسته‌ای/۸ CVE، Prometheus تعداد ۱۰، Grafana تعداد
۶۱ و Node Exporter تعداد ۱۴. اسکنر برای ۸۵ یافتهٔ سرویس‌های مانیتورینگ اصلاح
شناخته‌شده گزارش کرده است. اصلاح imageهای مربوط یا پذیرش ریسک مستند لازم است؛
هیچ suppression برای پنهان‌کردن نتیجه اعمال نشده است.

ورود حساب واقعی از ۱۳ حساب اولیه، به‌دلیل نبود اعتبارنامهٔ محافظت‌شده، تأیید
نشده است؛ حساب‌های آزمایشی موجود روی هر دو runtime تست شدند. manifest/guard
مهاجرت باید برای همین digest بازبینی و تأیید شود. بکاپ آنلاین جایگزین بکاپ
نهایی پس از توقف نویسنده نیست. اعلان بیرونی alert و بکاپ خارج از میزبان نیز
پیکربندی/تأیید نشده‌اند.

نشده است؛ برآورد صرفاً برنامه‌ریزی برای پنجرهٔ maintenance و کنترل‌های نهایی
